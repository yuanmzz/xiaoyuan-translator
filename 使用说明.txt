🐮 小袁翻译 - 使用说明（v1.0）

【文件说明】
小袁翻译.exe / XiaoYuanTranslator-v1.0.0.exe（21MB，单文件绿色版，无需安装Python）
  ※ GitHub Release 下载的文件名是英文版，两者内容完全一样
main.py            （源码，Python 可直接运行）
niulai.png         （牛来头像，换同名图即可自定义）
dist/              （打包输出目录）

【使用方法】
1. 双击 exe（首次启动等 5~10 秒，单文件需解包）
   - 右上角弹出 "🐮 小袁翻译已启动" 提示（3.5 秒后消失）
   - 系统托盘出现牛来图标

2. 悬浮翻译：去任意地方选中文字（浏览器、Word、微信、PDF等）
   - 拖动或双击选中一段文字
   - 鼠标左下角淡出牛来头像（56px，4 秒无操作自动消失）

3. 点击牛来
   - 在选中文字正上方弹出翻译卡片
   - 默认自动检测 → 中文；顶部下拉可换 28 种语言任意互译
   - 显示原文 + 译文，另有音标 / 简明释义 / 双语例句（短词才有）

4. 卡片操作
   - ⇄：源/目标语言互换
   - 📋 复制译文：复制到剪贴板
   - 🔊 原文 / 🔊 译文：分别朗读（本地嗓音→在线语音→装包指引）
   - 🔁 重试：仅翻译失败时出现
   - 拖动标题栏可移动卡片；ESC / 点空白 / 滚轮关闭
   - 朗读中关卡片会自动停读

5. 主窗口（词典式自主互译）
   - 右键托盘 → 打开主窗口（双击托盘也行）
   - 输入文字，Ctrl+Enter 翻译；有音标、简明/例句选项卡、历史 30 条（双击重查）
   - 建桌面快捷方式并在目标后加 " --main"，双击直进主窗口

【复制粘贴说明】
- 软件取词后会自动恢复你原来的剪贴板，不影响正常复制
- 复制A → 选中B → Ctrl+V，可直接把 B 替换成 A
- 想复制选中的 B，再按一次 Ctrl+C 即可

【退出】
- 右键托盘图标 → 退出小袁翻译
- 或任务管理器结束 "小袁翻译.exe"

【常见问题】
- 蓝屏 SmartScreen 拦截？
  → 点"更多信息" → "仍要运行"（未签名 exe 都会弹，正常）
  → 若点了仍没反应，去杀软隔离区恢复并加白名单

- 选中没反应？
  → 请以管理员身份运行（右键 exe → 以管理员身份运行）
  → 确保真正选中了文字（有蓝色背景），不是单击
  → CAD 类软件（AutoCAD/中望/浩辰等）里默认不取词：模拟 Ctrl+C 会触发 COPYCLIP 打断画图；要翻译请用主窗口手动粘贴

- 翻译失败？
  → 点卡片左下 🔁 重试；检查网络（首次稍慢 1~2 秒正常）

- 朗读没声？
  → 按提示装对应语言包：设置 → 时间和语言 → 语言和区域 → 添加语言 → 勾选"语音"
  → 联网时日语等会自动用在线语音，无需装包

- 杀毒软件报毒？
  → PyInstaller 单文件偶尔误报，加白名单即可，源码 main.py 可自行审查
  → GitHub Release 页可核对 SHA256

- 开机自启？
  → Win+R 输入 shell:startup，把 exe 快捷方式放进去

- 换头像？
  → 正方形图改名 niulai.png 放 exe 同级目录，重启即生效

python main.py
python main.py --main   （直接打开主窗口）
